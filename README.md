# jeremy-wine

Jeremy's wine guide: a searchable, mobile-first version of his tasting log.

**Live site:** https://jeremys-wine.up.railway.app/

The site is hosted on Railway (Caddy static server). This repo's `gh-pages` branch only serves a redirect, so https://webgophers.github.io/jeremy-wine/ forwards to the live site. The full source, including `wines.json` (all the content) and the bottle/grape images, lives in `/workspace/jeremy-wine-site/` on the box; see its README for how to update and redeploy.
